What should I put for the period?
Usually the calendar quarter — January to March 2025. Fine for most companies. But for one whose financial year does not start in January, sources often use this same label for their fiscal Q1 instead, which is why the explicit forms below exist.
The company's own financial year, which often does not start in January. NVIDIA's FY2025 began in February 2024 — so this can be almost a year earlier than the calendar quarter of the same name.
The calendar quarter, said explicitly. The same three months as "Q1 2025" — it changes nothing about the period, only about how much the agents have to guess. Worth using whenever a company's financial year might not match the calendar.

Also accepted: FY2024, H1 2025, 2023-2025. A year is always required — without one the agents would pick a year silently and the report would never say which. Saying FY or CY settles what you asked for; the sources can still label a figure loosely, so the report tells you which period each one covers.

Every figure is checked against retrieved sources. The provenance line says how much of the report is actually backed by one — read it before trusting a number.
